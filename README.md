# laporwarga-itechnocup26
LaporWarga adalah platform web inovatif untuk ajang ITECHNO CUP 2026 yang mendukung SDG 9 &amp; 11. Aplikasi ini memungkinkan warga melaporkan kerusakan fasilitas umum tanpa registrasi, serta menyediakan *dashboard* bagi RT/RW untuk memantau penyelesaian masalah secara transparan.
